
# МТС IMPULSE — Admin

Административная панель корпоративной платформы.

## Возможности

- Управление сотрудниками
- Создание и публикация игр
- Загрузка обучающих материалов
- Назначение заданий стажёрам
- Управление турнирами
- Просмотр рейтингов
- Контроль рекордов
- Аналитика обучения
- Управление наставниками

## Технологии

Next.js, TypeScript, Supabase.
