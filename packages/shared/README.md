
# МТС IMPULSE — Shared

Общие типы данных и бизнес-логика платформы.

## Основные сущности

- Employee — сотрудник
- Game — игра
- Quest — обучающий квест
- Material — учебный материал
- Achievement — достижение
- Tournament — турнир
- Leaderboard — рейтинг
- MoodEntry — настроение

## Система баллов

XP — учебный опыт.

Game Points — игровые баллы.

Учебный опыт и игровые баллы
учитываются отдельно.

## Использование

Библиотека используется мобильным
приложением и административной панелью.
