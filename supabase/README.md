
# МТС IMPULSE — Backend

Серверная инфраструктура корпоративной платформы.

## База данных

PostgreSQL через Supabase.

## Основные таблицы

- profiles — сотрудники
- teams — команды
- content — игры и материалы
- assignments — задания
- completions — прохождения
- game_attempts — игровые попытки
- xp_transactions — учебные баллы
- point_transactions — игровые баллы
- mood_entries — настроение
- tournaments — турниры
- audit_logs — история действий

## Безопасность

- Авторизация сотрудников
- Разграничение ролей
- Защита персональных данных
- Серверная проверка результатов
- Контроль начисления баллов
